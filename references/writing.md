# Markdown 论文与图表

## 开始写作的前提

论文写作安排在实验之后。创建或续写paper/paper.md之前，逐项检查：

1. 本轮执行范围明确包含S6或指定的论文写作任务。
2. 本次研究范围内全部计划内实验及必要验证已经实际完成；各问题均有有效结果或推导依据，不仅是第一问或基线完成。
3. G4/G5对应的检查有真实、仍有效的证据；必要实验或检验不存在TODO、DOING、BLOCKED、STALE或未处理的失败。
4. 实验清单、结果文件、日志、图表数据和主要结论已核对，负面结果与局限如实保留。

明确取消的可选探索应有范围调整理由和记录，不要求无限追加实验；必要实验不能为提前写作而改为可选或跳过。纯理论题以计划内推导、边界验算和必要数值核验完成作为相应前提，不制造不必要实验。

仅接手写作时先核验用户提供的既有实验及审查材料，记录与G4/G5相当的检查依据；已有有效成果无需重跑，未核实材料不能视为通过。上游不满足时给出精确缺口和补齐任务，保持写作受阻，不生成正文、摘要或“待填结果”的论文。

实验阶段可以维护reports中的问题分析、数学推导、文献记录、实验表和真实结果图，它们用于研究记录，不提前组装论文。开始写作后若新增实验或发现结果错误，暂停受影响的结论写作，回到对应实验阶段，完成后再更新论文。

## 输出约定

以 paper/paper.md 为最终论文。不得引入任何竞赛排版模板、Typst/LaTeX工程、Word或PDF。使用Markdown中的数学语法表达公式即可。用户以后明确追加其他格式时作为独立扩展。

按真实题目组织标题；可包含摘要、问题分析、假设与符号、逐问建模与求解、检验、结论与局限、参考文献，以及有必要的附录。不是固定章节模板：理论题、统计题和多阶段优化题可以不同；不要固定三问。

每问交代目标、依据、公式、算法、实际结果、检验与意义。分析稿明确标注阶段，最终稿清理未完成占位，不为了清理占位而编造内容。

## 数学表达

行内用 $x_i$，独立公式用 $$...$$。首次解释符号、单位、下标范围和参数来源。重要公式编号一致；需要推导时交代关键逻辑，不只罗列公式。

公式中的数值常数需分清给定条件、文献参数、估计结果或数值设置。统计误差、理论界限和经验结果使用准确名称。

## 结果与证据绑定

读取 evidence.md；使用隐藏HTML注释把关键数字绑定到具体实验、JSON位置、单位和场景。注释不显示在普通Markdown正文中，但保留在交付源文件中以便审计。

正文、摘要和表格多次出现同一指标时使用各自唯一的引用ID，指向同一源指标。展示精度明确，保留原始计算精度，单位转换先在结果文件中明确产生对应指标。

除绑定数字外，人工核对引用文献数字、题设常数、符号公式和解释性结论。自动脚本无法确认所有未绑定数字或语义。

## 数据图与概念图

读取 figures.md，按实验分析图与概念图两条路径执行。实验图由真实数据和绘图代码生成，统一视觉风格并核对统计含义；不能用生成式图像、占位图或未标注的仿真冒充实测结果。

论文框架图和流程图默认提供 GPT Image 提示词包，精确绑定实际方法的节点和连线。未请求生成图片时只交付提示词，不声称已有图片；不插入不存在的图片路径。必要成图未完成时保留待办，可选图明确不纳入本次成图交付。

图片用相对于 paper.md 的路径，如 ../figures/q1_error.png；保留源数据、绘图代码、图注与逐图检查记录。图注交代轴名、单位、条件、样本与误差含义。对比条件保持可比，代表性案例说明选择依据。无信息增量的图删除，不机械要求每问一张框架图。

## 引用与AI记录

仅列出真实核实的来源。采用一致的编号或作者年份方式，并确保正文与文末一一对应；链接优先官方原文、论文DOI或可核实出版信息。

保留报告中的检索记录：来源、所支持内容、实际读取范围、引用位置。没有原文依据时降低表述强度。

遵循当届AI使用规定，记录工具、使用时间、用途、输入输出范围、采用内容和核验方式；正式声明按实际要求写。清理内部日志不等于删除应披露的AI使用事实。

## 完稿与交付检查

摘要在结果确定后定稿，覆盖重要任务及有依据的结果。结论说明实际意义和适用范围，优缺点具体对应模型。

检查Markdown标题、表格、公式分隔、图片和链接；能预览时检查实际呈现。无渲染能力时记录未执行视觉预览，不谎称逐页或版式检查通过。

纸稿无占位文本、虚构文献、失效图片和过期结果。内部plan、todo、机器环境细节留在支持材料；论文保留复现所需科学细节和必要声明。

最终答复给出论文入口、主要支持文件、完成的验证与具体局限。Markdown完成不等于官方提交完成。
