# 模型选择与科学检查

## 通用顺序

先根据题目定义估计对象/决策对象和目标，再检查数据支持与约束，随后选择模型与求解器。将候选方法写成“适用理由、必要假设、风险、验证、预算”。不按题目关键词或样本数量单独指定算法。

区分事实、假设、推导、经验观察和外推。重要参数与外部公式给出可核实依据；文献未读原文的部分不得假装已经核实。

每个基线应足以建立参照，主方案应针对基线的具体不足。结果相当时，考虑可解释性、稳定性和运行成本，不为了复杂而替换。

## 优化、调度与网络

- 明确min/max、变量连续/整数/二元、定义域和所有硬约束。资源可共享与时间先后必须明确。
- 先确认可行性；独立代回原约束并报告残差、松弛量和容差。连续松弛后取整需要重验。
- 区分最优解、容差内最优、当前最好可行解、局部最优和无可行解。多随机种子稳定不能证明全局最优；小规模精确对照只证明其覆盖实例。
- 记录求解器状态、目标值、可用上下界/最优性间隙和时间限制；无证据不声称全局最优。
- 非线性问题先检查结构、尺度、凸性/光滑性、可用梯度和约束，再选择数值或启发式算法。
- 多目标先解释量纲与偏好。可无量纲化，或采用有明确单位换算/效用含义的权重；不能随意相加。
- 路径检查子回路、方向、容量、时间窗、前驱和连通性。几何实体检查真实边界，近似需说明误差。
- 核对所用软件版本的接口文档，不能把某一API的约束符号规则推广到所有求解器。

## 预测、分类与统计

- 根据预测时点确定当时可获得的信息。划分遵循时间、对象和空间依赖，预处理只在训练部分拟合。
- 调参用验证数据；保留独立最终评价，或采用与规模相适应且明确报告的验证协议。不固定划分比例。
- 小样本先评估有效信息量和模型复杂度，考虑朴素预测、简单回归或领域模型；不自动选择灰色预测或深度网络。
- 主指标对应实际目标；类别不平衡时结合类别表现和决策代价。接近零的真实值会影响某些相对误差指标。
- 残差诊断分别分析函数形式、独立性、异方差、极端点和估计目标。残差非正态不自动使预测或参数估计无效；推断可能需要相应稳健方法。
- 相关性、特征重要性和预测能力不能直接证明因果。SHAP等解释依赖模型、背景分布和特征依赖假设。
- 不把不显著解释为没有影响，不把缺乏检验能力解释为等效。区间估计说明依据及限制。
- Bootstrap重采样应尊重对象/时间依赖；Monte Carlo停止依据误差或置信区间精度及预算，不固定采样数。

## 机理、动力学与反问题

- 写清状态、单位、初始/边界条件、控制输入、参数来源和可辨识性。
- 检查守恒、非负性、平衡点、极限、数量级和已知解析特例。
- 数值误差检查使用与任务精度匹配的绝对/相对容差；有需要时采用多级步长或网格加密，不能以统一1%阈值取代论证。
- 区分模型误差、参数不确定性、数值误差和观测噪声。选择符合刚性等性质的数值方法。
- 多参数组合都能解释观测时，减少自由度、增加有依据条件或报告可行范围，不虚构唯一真值。
- 马尔可夫链区分平稳分布存在、唯一性和收敛；有限状态链的存在不要求非周期，不能混用这些条件。

## 综合评价与决策

- 先界定评价对象、价值目标和指标含义，再决定赋权和排序。
- 核对指标方向、尺度、重复信息、缺失处理及权重来源。数据离散程度不等同业务重要性。
- AHP判断需有实际依据；一致性检查不证明偏好或结论真实。
- TOPSIS/PCA等方法需要解释归一化、相关性和结果含义；降维可能损失业务解释，不能作为固定搭配。
- 检查合理权重/处理规则下的排序稳定性，说明名次变化和接近程度，不把微小分数差距夸大成确定优势。

## 验证与停止

| 任务 | 应检查的证据 |
| --- | --- |
| 基础正确性 | 手算/已知解小实例、边界、单位、约束、输入输出对应 |
| 模型有效性 | 适用条件、数据支持、合理对照、样本外或理论/机理证据 |
| 敏感性 | 合理参数变化对关心的输出影响，扰动范围有依据 |
| 稳健性 | 不利但合理条件下表现，明确情景范围 |
| 不确定性 | 来源、区间或情景范围及其计算依据 |
| 设计贡献 | 保持其他条件可比的受控比较 |
| 可复现性 | 输入版本、代码、环境、参数、种子、求解设置、日志与输出 |

完成支撑主要结论的必要检验后停止可选测试；剩余预算不足则降低扩展目标，不伪造证据。资料检索优先原始论文、官方文档和权威原文，记录实际读取的来源。
